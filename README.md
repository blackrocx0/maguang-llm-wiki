# 馬光 LLM Wiki｜Codex 知識庫體驗包

用 Codex 體驗 Andrej Karpathy 的 [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 架構：把散落的 SOP、會議紀錄、群組對話、Email 丟進 `raw/`，讓 AI 自己整理成互相連結、會持續更新的 `wiki/`。

> 素材聲明：`raw/` 內 38 份素材皆為教學模擬，人物、院所、數據皆為虛構，不代表馬光醫療網正式規範。

## 怎麼開始

1. 打開 Codex（App、CLI 或 IDE 擴充都可以），選一個空資料夾作為專案。
2. 把 [`PROMPT.md`](PROMPT.md) 的全文貼進 Codex 送出。
3. Codex 會自動下載這個範本、讀懂規則、消化全部素材，最後示範一次問答。

整個過程約 10–20 分鐘，視模型速度而定。下載時如果 Codex 請求網路權限，請按允許。

## 資料夾結構

```
maguang-llm-wiki/
├── AGENTS.md              ← 規則檔（Codex 每次開啟都會自動讀）
├── PROMPT.md              ← 學員貼上 Codex 的提示詞
├── .agents/skills/        ← 四個技能，輸入 $ 呼叫
│   ├── ingest/SKILL.md    ← 消化 raw/ 新素材
│   ├── query/SKILL.md     ← 從 wiki 找答案
│   ├── lint/SKILL.md      ← 健康檢查
│   └── capture/SKILL.md   ← 對話中的新資訊自動收錄進 raw/
├── raw/                   ← 原始素材（AI 只讀不改）
└── wiki/
    ├── index.md           ← 依分類整理的目錄
    └── log.md             ← 只增不刪的操作紀錄
```

## 四個技能

| 技能 | 用途 | 範例 |
|------|------|------|
| `$ingest` | 消化新素材進 wiki | `$ingest`、`$ingest raw/我的筆記.md` |
| `$query` | 向知識庫提問 | `$query 中一院爽約率為什麼偏高？` |
| `$lint` | 檢查孤立頁、壞連結、矛盾、過時、空白頁、個資、未消化素材 | `$lint` |
| `$capture` | 對話中提到新規定、決議、數據時，自動存成 raw/ 新檔並更新 wiki | 自動判斷 |

技能只有在 Codex 以 `maguang-llm-wiki` 資料夾為專案開啟時才會自動載入。

## 帶回自己的工作

- 把自己的文件放進 `raw/` 前，先移除病患姓名、電話、身分證字號、病歷號。
- 依公司 AI 工具使用規範，確認哪些資料可以交給 AI 處理。
- AI 整理的內容是草稿，引用時以原始公告為準。
