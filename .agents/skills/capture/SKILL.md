# Capture 自動收錄

用途：把對話中出現的新資訊存成 `raw/` 新素材，讓知識庫越用越完整。

## 判斷是否收錄
應該收錄（符合任一項）：
- 新事實：raw/ 與 wiki/ 都沒有的新規定、流程變更、會議決議、數據、案例經驗、踩雷教訓。
- 更正：使用者指出既有內容已經改變。
- 貼上內容：文件、Email、對話紀錄、表格。

不收錄：單純提問、閒聊、要求改寫或排版、wiki 已有且無新資訊、使用者說「不用存」。
拿不準時：收錄，但在檔案標 `可信度：待確認`。

## 步驟
1. 去識別化：病患姓名、電話、身分證字號、病歷號改成描述（例：「60 多歲男性複診病患」）；同事姓名保留職稱即可。
2. 建立新檔：`raw/YYYY-MM-DD_對話收錄_主題.md`，主題用 4–10 個中文字。若同名檔已存在，在檔名後加 `-2`。
3. 檔案格式：
   ```
   ---
   來源類型：對話收錄
   日期：YYYY-MM-DD
   提供者：使用者（職務，若有提到）
   可信度：使用者陳述／待確認
   ---

   # 主題

   ## 內容
   （忠實整理使用者提供的資訊，不加入推測）

   ## 與既有知識的關係
   （補充或更正了哪些 wiki 頁面）
   ```
4. 依 `.agents/skills/ingest/SKILL.md` 只 ingest 這個新檔。
5. 在 `wiki/log.md` 新增：`[YYYY-MM-DD] [CAPTURE] raw/檔名 ← 對話收錄：一句話摘要`（ingest 紀錄另記一筆 INGEST）。
6. 回覆最後加一行：「已收錄：raw/檔名，並更新 [[頁面]]。若不想收錄，回覆『不要收錄』。」

## 撤銷
使用者回「不要收錄」時：刪除剛建立的 raw 檔、還原這次對相關 wiki 頁面與 index 的修改，並在 log 新增 `[YYYY-MM-DD] [UPDATE] 撤銷收錄 raw/檔名`。

用法：自動執行；也可輸入 `$capture 要收錄的內容`
