# Query 知識庫

用途：從 wiki 找答案並合成回應。

## 步驟
1. 分析問題，列出相關主題關鍵字。
2. 先讀 `wiki/index.md`，再搜尋 `wiki/` 相關頁面；wiki 沒有答案時，才回頭查 `raw/`，並提醒使用者「這部分尚未 ingest」。
3. 合成答案：結論先講，再列細節；每個重點標注引用來源 `[[檔名|中文標題]]`。遇到規則衝突或待確認事項，要明講目前適用哪一版、哪裡還不確定。
4. 判斷答案是否有保存價值（跨多頁整理、比較、時間軸、決策建議），有的話寫成新的 wiki 問答沉澱頁，並更新 `wiki/index.md` 的「問答沉澱」分類。
5. 在 `wiki/log.md` 新增：`[YYYY-MM-DD] [QUERY] 問題摘要 → 引用 a、b（是否存成新頁）`
6. 依 `AGENTS.md`「自動收錄」規則判斷：使用者的提問裡如果夾帶新資訊，同時執行 `$capture`。

用法：`$query 你的問題`
