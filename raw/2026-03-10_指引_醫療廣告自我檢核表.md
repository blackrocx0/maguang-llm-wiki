# 醫療廣告自我檢核表

所有對外內容（LINE 推播、社群貼文、海報、活動文宣、院所門口公告）發布前，請先用本表自我檢核，再送法務審查。

## 背景
醫療法對醫療廣告有嚴格規範：醫療廣告可以刊登的內容有法定範圍，也禁止以特定方式宣傳；違反者可能遭主管機關裁罰。
> ⚠️ 待確認：條文細節與罰則金額，以主管機關最新公告及法務意見為準，本表僅為內部提醒。

## 檢核項目（任何一項勾「是」，就不能發布）
| # | 檢核問題 | 是／否 |
|---|----------|--------|
| 1 | 是否宣稱或暗示療效？（例：改善、根治、有效、調好體質、幾次見效） | |
| 2 | 是否使用病患見證、感謝函、治療前後對比？ | |
| 3 | 是否提供折扣、贈品、免掛號費、抽獎等招攬病患的誘因？ | |
| 4 | 是否以「衛教文章」包裝，實際上在推薦本院特定療程？ | |
| 5 | 是否使用「最好」「第一」「保證」等誇大或比較性用語？ | |
| 6 | 是否透過他人名義（網紅、KOL）宣傳本院醫療服務？ | |
| 7 | 是否提及特定疾病並暗示本院可以治療？ | |

## 可以放心使用的內容
- 院所名稱、地址、電話、交通方式、門診時間。
- 醫師姓名、專科、學經歷。
- 預約方式、開幕或休診公告。
- 一般生活資訊（節氣、天氣提醒），不連結到本院療程或療效。

## 送審流程
行銷部初稿 → 自我檢核 → 法務審查（3 個工作天）→ 修改 → 發布。急件請先電話告知法務。
